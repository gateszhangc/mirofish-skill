# MiroFish — Agent Skill

> AI multi-agent simulation engine for scenario prediction and decision rehearsal.

This repository contains the **MiroFish Agent Skill** (`SKILL.md`) for use with AI coding agents like Cursor, Claude Code, GitHub Copilot, and any MCP-compatible platform.

## What It Does

MiroFish spawns AI personas with distinct incentives, biases, and memory, then lets them interact across social surfaces over multiple rounds to surface emergent dynamics — things you can't get from single-model Q&A.

## Quick Links

- **Live App**: [mirofish.homes](https://mirofish.homes/)

## Install

```bash
npx skills add 666ghj/mirofish-skill
```

Or manually: clone this repo and reference the `SKILL.md` in your agent's skills directory.
